# Assignment 1: What Happens When You Open a Website

When I type a website address and press Enter, the browser finds the server for that website. It sends a request to the server. The server sends back the page files, such as HTML, CSS and images. The browser reads the HTML to understand the page structure and reads the CSS to style it. It then displays the page on the screen. For secure websites, HTTPS helps protect data sent between the browser and server.

## Main steps

1. Enter the website address.
2. The browser finds the server address.
3. The browser sends a request.
4. The server sends a response.
5. The browser reads HTML and CSS.
6. The browser displays the page.
