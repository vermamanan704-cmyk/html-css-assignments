# Assignment 5: Publish the Project on GitHub

## Repository details

GitHub username: `vermamanan704-cmyk`

Repository name: `html-css-assignments`

Target link after the repository is created: https://github.com/vermamanan704-cmyk/html-css-assignments

## Steps

1. Open GitHub and click New repository.
2. Enter `html-css-assignments` as the repository name.
3. Choose Public if your teacher needs to view it. Leave the new repository empty.
4. Open the prepared project folder in VS Code.
5. Open Terminal and run these commands:

```powershell
git remote add origin https://github.com/vermamanan704-cmyk/html-css-assignments.git
git branch -M main
git push -u origin main
```

6. Complete any GitHub login prompt in your browser.
7. Open the repository page and check that the files and commits are visible.

The target link will work after the repository is created and the push succeeds. Never share a password or access token in a project file.

Official guide: https://docs.github.com/en/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github
