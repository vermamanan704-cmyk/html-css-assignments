## Open the project

1. Extract the ZIP file.
2. Open VS Code.
3. Choose File, then Open Folder.
4. Select the `html-css-assignments` folder.
5. Open any numbered HTML file in a browser. Live Server is optional but useful.
6. Read the Markdown files for Assignments 1 to 5.
